# 功能状态（2026-11-16）

## PixelOS 17 本轮实测

当前真机 B 槽已升级为 `PixelOS_m2381-17.0-20261115-0353`，Android 17 / SDK 37，安全补丁 2026-11-01。七个逻辑分区均按物理区段回读 SHA-256，与校验后的候选一致；五个启动/AVB 分区也已从手机回读摘要验证。首次约 34 秒完成启动，随后一次正常重启成功；用户确认桌面画面和触摸正常。未擦除用户数据，升级前完整 super、启动分区和诊断目录备份保留。

本轮通过：ARM/ARM64 OpenGL ES 2.0–3.2 绘制各 4/4、Chrome 启动并持续存活、Wi-Fi 联网验证及重启自动重连、蓝牙开启且无管理器崩溃、主摄持续预览、颜色设置页启动、设备资源覆盖启用。蓝牙配对/传输/音频、全部相机 JPEG、震动手感和其他硬件未全部重测，不能沿用旧版测试直接标为本版通过。

仍依赖第 48 组诊断 ramdisk 和 metadata；SELinux permissive、CPU idle state1 关闭、模块 blocklist 等诊断限制保留。`vendor.dpmd` 缺少 `Parcel::setData` 的重启问题已在升级前日志中确认；另观察 `slim_daemon` 缺少 `__emutls_get_address`，尚未建立旧版对照。二者不影响本轮桌面/Wi-Fi 验证，但不表示对应厂商功能正常。曾因诊断命令使用管道截断 `dumpsys media.camera` 使 provider 收到 SIGPIPE，改为完整保存输出后主摄预览正常；该次采集引起的退出不作为自发崩溃证据。

后续充电修复：Health 上报、估时和快充分类已校正。原厂充电模块的独立兼容副本使 PD 不再接受 USB Gadget 枚举限流，连续四次保持电脑连接重启后均保留 3A 协商限流并实际取电，电量升至 100%；ADB 数据校验通过；用户连接快充头后切回同台电脑，输入约 0.862A、ICL 3A，ADB 正常，未复现零限流。满电下未验证大功率快充。原厂模块未改写，运行交付仍依赖早期 metadata 挂载，源码内核替代、其他电源类型和长期热管理尚未全部验证，见 [充电适配](charging.md)。

后续待机修复：s2idle 挂起期间看门狗 panic 已捕获，设备 init 在厂商启动脚本退出后选择 deep；正常重启后拔线测试记录 28 次成功挂起，启动 ID 和系统进程未变，无新 panic。长期功耗尚未验证，见 [待机适配](suspend-adaptation.md)。

后续指纹修复：恢复原厂中心 `(540,1796)`、尺寸 `190×190`，修复图标越出屏幕的问题。用户确认位置正确、录入与锁屏解锁成功，系统确认 1 枚指纹及成功认证；应用和支付认证等未完整验证，见 [指纹适配](fingerprint-adaptation.md)。

升级流程、离线验证和实际限制见 [PixelOS 17 升级](upgrade-pixelos17.md)。下表保留 2026-11-14 的 Android 16 观察，用于区分历史硬件证据。

## 锁屏日期越界

当前选择的 `DIGITAL_CLOCK_NUMBEROVERLAP` 时钟，在正常字体缩放下也会出现日期超出 1080px 屏幕右边缘。已有布局记录约为 x=844..1131，涉及时钟宽度、Smartspace 日期列及框架宽度阈值。**已定位现象，尚未修复**；不能归因于用户设置，也不能声称屏幕校准已经解决它。

## 构建与安全状态

上述历史版本构建于 2026-11-12，系统安全补丁显示 2026-06-01。`main` 保留该 16.2 基线；本分支的 Android 17 实测见本页开头，不能用旧版构建日期代表当前真机。

源码侧保留测试阶段 permissive、兼容旧厂商库的 ABI 补丁、AIDL 指纹声明版本调整等措施。抬高 VINTF 声明不等于驱动实现新接口。元数据诊断脚本还包含 root ADB 准备和启动监测，不能直接作为量产配置。

本次可执行的验证范围记录于 [validation.md](validation.md)。全新同步后的干净构建、正式 recovery、OTA/双槽升级和去掉诊断脚本后的启动均需后续完成。

## 设备树与 ROM 范围

原厂依赖现随 Git LFS 提供，默认内核已对齐现有诊断候选的去 KernelPatch 副本；原始 root 补丁备份不随附。设备公共配置已拆出，注册 PixelOS/LineageOS 两个产品。LineageOS 及其他衍生 ROM 尚未执行独立全量编译和启动验证，不能视为全部支持。
